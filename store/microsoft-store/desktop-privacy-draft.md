# LocalMorph Desktop privacy policy - review draft

This draft describes the desktop application's current behavior. Review it, add an effective
date, identify the responsible publisher and contact details, and publish it at a public URL
before using it as the Store privacy policy. It is not a statement that legal review is complete.

## Local file processing

LocalMorph Desktop reads files and metadata that you choose to open or add to its queue.
Conversion tools run on your computer. LocalMorph does not upload your source files to a
conversion server.

## Information stored on your computer

The app stores preferences, including selected output options and appearance, in local app
storage. Conversion history may include original and result file paths, formats, requested
options, operation details, file sizes, and completion information. These records are used to
show previous conversions and help you find or repeat an operation.

The app and its conversion tools may create local working files and diagnostics. Completed
outputs remain in the location chosen for the conversion. Removing an entry from history does
not remove the corresponding source or result files.

You can remove individual history entries in the app. You can manage or remove other app data
using the operating system's app-data controls where available. Uninstalling the app is not
a promise to delete converted files saved outside its private app storage.

## Network access and external services

The Microsoft Store edition receives app updates through Microsoft Store. An explicit
update action may open the Store. Direct-download editions may request an update feed from
localmorph.com; web hosting services can receive ordinary network information associated with
those requests. These update requests do not include the source media files.

The Tools page can open external installation, codec, or project links. FFmpeg and FFprobe
must be installed separately for media processing. Tool and codec installation may use
Windows Package Manager, Microsoft Store, or the tool publisher's website. Those services have their
own privacy policies and licenses. Opening support or website links also contacts those
services.

## Diagnostics and support

LocalMorph can show or copy conversion diagnostics at your request. Diagnostics can include
local file paths and tool commands. Review them before sharing. If you choose to open a
public GitHub issue, do not attach confidential files or personal information.

## External components

External conversion tools and Windows codecs operate under their own licenses. Review the
components you install and use, especially when working with sensitive files.

## Publisher and contact

To be completed by the publisher before publication: responsible business/entity, privacy
contact, effective date, and any disclosures required for your distribution and jurisdictions.
